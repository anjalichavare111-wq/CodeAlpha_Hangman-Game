# CodeAlpha Hangman Game

A simple text-based Hangman game built using Python.

## Internship Task
CodeAlpha Python Programming Internship - Task 1

## Features
- 5 predefined words
- Random word selection
- Maximum 6 incorrect guesses
- Input validation
- Win and lose conditions

## Requirements
Python 3

## How to Run
python hangman.py
